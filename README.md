# 🎬 Diboh MovieBlast

A premium, fast, and legal movie discovery platform. Built with HTML5, CSS3, Vanilla JavaScript, and JSON. Deployed on GitHub Pages.

## 🚀 Features
- **Premium Cinematic UI:** Dark theme with smooth animations and responsive design.
- **Dual Language:** Default English with a Bangla language switcher.
- **Advanced Filtering:** Search by title, filter by genre/language, and sort by latest/popular.
- **Legal & Safe:** Only features Public Domain movies from authorized archives (Internet Archive).
- **SEO Optimized:** Includes `sitemap.xml`, `robots.txt`, and Open Graph tags.

## 📁 Project Structure
- `index.html` - Main homepage
- `assets/css/style.css` - Premium styles
- `assets/js/app.js` - Logic for search, filter, and language switching
- `data/movies.json` - Movie database
- `privacy.html`, `terms.html`, `copyright.html` - Legal pages

## 🛠️ How to Add New Movies (Admin Guide)
1. Open `data/movies.json`.
2. Copy an existing movie block and paste it at the end.
3. Update the `id`, `title`, `year`, `poster` (image link), and `downloadOptions` (links).
4. Save and push to GitHub: `git add .`, `git commit -m "New movie added"`, `git push`.
